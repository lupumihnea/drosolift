    An inspectable model, from signal to lift

    Official MaleCNS v1.0 identities, measured soma positions and compact structural connectivity drive the upstream rate model. The anatomical overview contains many more measured cells than the compact circuit observes. Unobserved cells have no activity reading.

    The fly is an original procedural articulated illustration (Apache-2.0), enlarged for this virtual apparatus. Anatomy, force conversion, support pose and gym mechanics are authored; this is not a biological exercise simulation. No invented spikes or propagation events are shown.

    Apparatus feedback: the demo's visible indicator lights encode joint position, virtual load and recovery. Their synthetic brightness enters the existing model visual-input channels. Different activity during bench presses and curls reflects this engineered task input, not a claim of biologically specialized exercise regions. Baseline recordings and the fixed-budget comparison retain their original feedback-free model.

    Training: each fly has independent neural state, fatigue and learning memories within the same pinned model. A set of three full repetitions earns +0.005 fitness, capped at 1.5. Conditioning supports force under fatigue; it does not exceed the rested peak force. Fitness and workout totals last for this server run; food/gym learning memories are saved separately. All active flies train on the shared model clock. Pause freezes the clock and recovery.

    Force calibration: F = 6 × clamp(forward, 0, 1) × min(1, (1 − 0.75 × fatigue) × fitness). Load, force, distance and work use virtual model units, not kilograms or SI. Gravity = 1; joint damping = 3. A full upper-stop-to-bottom return counts one repetition; three repetitions make one set.

    The soma atlas uses normalized source coordinates, with display Y inverted. X-ray adds a schematic layout of official cells and connections inside the faded body. Values and identities are received; placement is illustrative, with no anatomical registration of the atlas inside the body. Exact values remain inspectable alongside the rate-driven display.
