# DrosoLift observatory and portable replay

Date: 4 November 2026. Base: `2c5a03aa90f01048f011e13546b4d7fffc693945`.

The handoff authorizes an English gym presentation and bounded load commands,
superseding the earlier Persian-only presentation and pause/population command
restriction within this implementation. Other upstream scientific and engineering
rules remain applicable; their full text is retained in AGENTS.md.

The running gym reuses Python/aiohttp, immutable snapshots, rate dynamics, actual
equipment integration, TypeScript/Three.js and official soma positions. Load
commands negotiate an additive control protocol, retaining legacy message shapes.
Python acknowledges effective steps and applies queued loads at a rack/bottom
boundary. Observer controls do not alter model state. Recorded replay chooses
exact time-stamped states independently of optional pose smoothing.

The prior walking GLB has no supplied redistribution permission. The distributed
runtime instead uses original Apache-2.0 procedural geometry and a reproducible
six-leg rig; upstream assets and notices remain in source history. Two official
CC BY 4.0 SWCs use the same normalized native atlas frame as measured somata.
No body registration or modeled spikes are invented. See the asset and morphology
records for hashes, transformations and source versions.

An untouched startup exceeded ten minutes and paged over 5 GB while hydrating the
151-million-row weights table. Bounded Arrow record-batch validation preserves
full-file SHA256 and exact selected triples/count/row semantics with about 227 MB
startup working memory. Network dynamics are unchanged. This is a measured
environment repair, not a bypass of official provenance validation.

The replay build defaults to a bundled, source-validated 20-second recording and
uses relative asset paths, allowing static root/subpath hosting without Python.
The conference archive contains only the static build and its notices/provenance.
Large raw sources, temporary tools and full experiment runs stay Git-ignored.

The comparison fixes a separately calibrated four-second recorded neural command
window and a matched-impulse rectangular controller before the load sweep. This
is an open-loop engineered-apparatus comparison, not online feedback validation
or an animal experiment. Exact results and limitations are retained even where
the periodic controller ties or performs more positive work.
